# Screenshot aplikasi

Screenshot dari production build pada Chrome, menggunakan akun dummy, database SQLite khusus QA dan pipeline mock. Semua dokumen sintetis. Ini bukan bukti deploy PostgreSQL, pipeline asli, atau review Orang 1.

Laman Login, Unggah, Kotak Verifikasi dan Arsip Saya ditangkap pada lebar 375 px dan 1280 px. Koreksi HP ditangkap hanya pada viewport agar modal fixed tidak tercampur dengan isi di luar layar. Pratinjau PDF ditangkap setelah viewer masuk viewport.

Wireframe awal disimpan terpisah di ../wireframe/. Hasil pemeriksaan dan dependensi eksternal dijelaskan di ../HANDOFF.md.

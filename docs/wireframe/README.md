# Wireframe empat laman

Delapan gambar PNG: Login, Unggah, Kotak Verifikasi, dan Arsip Saya, masing-masing pada lebar 375 px dan 1280 px. Ini referensi tata letak awal, bukan screenshot hasil implementasi dan bukan bukti persetujuan Orang 1.

Desain mengikuti kartu putih, latar abu polos, aksen biru tunggal, navigasi atas desktop dan navigasi bawah HP. Efek blur sebenarnya dinilai pada aplikasi berjalan. Font diagram memakai Arial sistem agar gambar dapat dibuat offline; frontend memakai Inter.

Regenerasi dari root:

```powershell
python tools/generate_wireframes.py
```
